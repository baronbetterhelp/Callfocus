# CallFocus V15.71 Visual Test — Direct Email CTA Layout Polish

Built directly on CallFocus V15.70.

## Change
Adjusted the call-to-action button in **Admin → Email → Direct customer message** emails so the CTA looks properly arranged in inbox view.

- CTA button is now horizontally centered in the email layout instead of sitting left-aligned.
- CTA block spacing was tightened so the button sits a bit higher and feels more connected to the closing/signature area.
- CTA button size was increased for clearer visibility and a stronger touch target.
- Button text remains optional and still requires a valid button link when used.
- Direct-message email content, recipient behavior, and non-promotional classification remain unchanged.

## Preserved
No changes to credits, payments, Cloudflare bindings, KV structure, authentication model, calls, voice features, or promotional email workflow.

Build version: `15.71-test`.
