# CallFocus V15.50 Visual Test — Promotional Audience Mobile Fix

V15.50 is a targeted Admin → Email responsive-layout correction built directly on V15.49.

## Fixed
- Corrected the promotional Audience cards on mobile where the globally styled radio input could expand to the full field width and push the option title/description outside the card.
- Radio controls are now fixed to a compact 22px circle.
- Audience option text is constrained to the available card width and wraps normally.
- Both “All active customers” and “Selected customers” remain fully readable on narrow iPhone screens.
- Added mobile spacing and text sizing adjustments without changing the desktop Email Studio layout.

## Preserved
The promotional email sender, Resend integration, recipient selection, unsubscribe protection, campaign history, calls, credits, referrals, payments, customer data, themes and all V15.49 functionality remain unchanged.

Build/app version: `15.50-test`.
