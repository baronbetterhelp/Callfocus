# CallFocus V15.7 — Dashboard Screenshot Controls

V15.7 moves the shared screenshot upload controls directly onto the Admin Dashboard so they are visible immediately after unlocking admin.

## Changes
- Added a prominent **Screenshot upload limits** card directly below the Dashboard heading.
- Admin can set **Minimum screenshots** and **Maximum screenshots** from 1–50.
- The saved limits continue to apply to both **Fill in all information automatically** and **Generate conversation dynamics**.
- The Worker now removes any stale/older copy of the limits control from another admin section and reinserts a fresh V15.7 copy on the Dashboard before serving `/admin`.
- Admin HTML, JS and CSS remain no-store/no-cache and the admin build marker is now 15.7.
- Existing calls, credits, payments, voices, customer accounts, AI usage tracking and other working features are preserved.
