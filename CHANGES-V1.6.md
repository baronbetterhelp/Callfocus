- Replaces the Home headline with **All working tools in one place.**

- Replaces the Home description with: **Easy access to all working tools. Launch products, catch updates and manage your tools in one account.**

Visible Admin labels use **Tools** instead of **Apps** while internal API/database identifiers remain unchanged for compatibility.
