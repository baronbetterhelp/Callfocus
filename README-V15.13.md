# CallFocus V15.13 — Opaque Mobile Menu Panel

Built directly on **V15.12**.

## What changed

- The slide-out mobile menu panel in the Pearl theme now uses a fully solid white background instead of a translucent white background.
- Backdrop filtering is disabled on the menu panel itself so Home-page content cannot visually bleed through the menu.
- The surrounding page overlay and the menu layout, buttons, navigation, account controls and existing feature behavior are otherwise unchanged.

## Versioning

Customer/admin asset references and `/api/app-version` are updated to `15.13`.
