# ToolCart V2.2 — Standard Dark + Hero Tool Launcher

Built on top of V2.1.

## What changed
- Moved the “Launch what matters” curated tools section directly into the main Home hero where the three metric cards previously sat.
- Removed the duplicated lower curated-tools section so the homepage reads more naturally.
- Limited the hero launcher to the first three tools, with “View all” opening the complete Tools page.
- Enlarged and rearranged the hero tool cards so each tool has a prominent icon, online status, title, and short description while remaining balanced on mobile.
- Reworked the customer UI into one standard premium dark theme: pure black page background, neutral dark-gray panels, white typography, restrained Apple-like blue links, and green availability status.
- Removed the customer Appearance toggle so the interface no longer switches to a light/pearl theme.
- Removed decorative purple/blue ambient washes from the main customer UI for a cleaner, more standard dark presentation.
- Preserved the V2.1 navigation/tool persistence fix.

## Notes
- No D1 migration required.
- Existing APIs, authentication, payments, admin tools and data remain unchanged.
