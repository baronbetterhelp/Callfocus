# CallFocus V15.17 Visual Test — Long-Form Motion & Premium Home Experience

Built directly on **V15.16** as an experimental visual test.

## Purpose

This build explores a longer, more cinematic CallFocus home page with richer motion and product storytelling inspired by the pacing of premium voice-AI product websites. It does not copy third-party branding, text, screenshots or assets.

## Visual changes

- Added layered hero aurora glows, a moving grid field and deeper background motion.
- Added a long-form “Continuity, visualized” section with three animated product-story cards for context, live conversation and memory-forward continuity.
- Added a dark immersive “Built around human rhythm” conversation stage with animated rings, live waveforms, floating context notes and moving caller nodes.
- Added a premium bento feature field for conversation memory, worldwide time awareness, voice profiles, translation transcript and saved setup continuity.
- Added a continuously moving “Prepare once / Call naturally / Keep the context / Continue later” ribbon before the final CTA.
- Added directional scroll-reveal motion and desktop pointer-reactive tilt/shine effects while respecting reduced-motion preferences.
- Kept the existing Pearl Aurora identity while increasing contrast, depth, spacing and visual rhythm.

## Product behavior preserved

No call, payment, credit, referral, authentication, saved-information, Quick Start admin, voice-note, recent-call or backend logic was intentionally redesigned. The new work is limited to home-page presentation and motion helpers.

## Test status

The build uses version string `15.17-test`. V15.16 should remain the rollback/stable base until this experiment is approved.
