# CallFocus V12.3 — Scrollable Admin Refresh

This build reorganizes the CallFocus Admin Portal into a clean horizontal, swipeable tab workspace for mobile and desktop.

## Admin layout
- Sticky horizontal admin tab bar with touch/trackpad scrolling
- Dashboard, Customers, AI usage, Voice, Behavior, Appearance and Diagnostics sections
- Only one admin section is shown at a time
- Active tab automatically scrolls into view
- Dashboard summary cards for calling status, customer accounts, funded users and AI analysis activity
- Single Refresh data action at the top
- Mobile-responsive spacing and panels

## AI usage visibility
- Records completed conversation-dynamics analyses
- Tracks screenshot count and OpenAI request/token usage when returned by the API
- Shows an estimated GPT-6 Luna API cost for administrative visibility
- Estimates are informational and may differ slightly from OpenAI's final billing records

No customer-facing CallFocus page layout was redesigned in this update.
