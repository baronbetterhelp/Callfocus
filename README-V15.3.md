# CallFocus V15.3 — First-Call Auto-Fill & Cloud-Saved Information

Built on V15.2 without removing existing features.

## New first-call auto-fill
- Adds an optional **Fill in all information automatically** button to the completely-new-call form.
- Customers enter their own name, age and job/work type, then upload 20–50 conversation screenshots.
- Uses the V15.2 low-memory image preparation approach and smaller mobile batches.
- Generates three separate editable results: About you, About the caller, and Dynamics of Your Conversations.
- Generated information is never written into the call form until the customer taps **Add generated information to call**.
- A supported caller name can also fill the caller-name field when it is still blank.
- The original standalone Conversation Dynamics Generator remains available.

## Save information for later
- Adds **Save information** beside Start call.
- Saves all first-call setup fields, including title, caller, both About fields, dynamics, topic, locations/time zones, language, selected voice/profile and opening configuration.
- Saved setups are stored inside the existing server-synced CallFocus account data, so they can be loaded after signing in on another browser/device.
- Customers can keep multiple saved setups, load them, update them and delete them.
- Explicit Save information performs an immediate account-data sync in addition to the normal background sync.

## Compatibility
- Preserves V15.2 screenshot stability changes, Telegram widget, Pearl Aurora design, authentication, credits/payments, live calls, voice notes, Recent Calls, My Callers, admin portal and responsive behavior.
- Asset query versions advanced to 15.3 to avoid stale cached JavaScript/CSS.
