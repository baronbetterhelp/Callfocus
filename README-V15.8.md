# CallFocus V15.8 — 10-Screenshot Customer Minimum

This release changes the customer screenshot-analysis minimum to **10 screenshots** while preserving the existing maximum of up to 50 screenshots.

The 10-screenshot minimum applies to both:

- **Fill in all information automatically**
- **Generate conversation dynamics**

The customer UI, counters, generate-button validation, and server-side analysis validation all enforce the 10-screenshot minimum. The existing low-memory image processing and all other CallFocus features are preserved.
