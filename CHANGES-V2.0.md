# ToolCart V2.0 — Premium Apple-Inspired Rebuild

Built as a fresh customer-facing visual rebuild.

## Direction
A complete redesign of the customer website experience with a more premium dark presentation inspired by modern high-end product pages: larger spacing, cleaner hierarchy, long-form homepage sections, and motion that feels more alive.

## What changed
- Rebuilt the public landing page and signed-in customer experience from scratch.
- Introduced a longer, more cinematic homepage with larger sections and stronger visual hierarchy.
- Replaced the cramped home layout with a premium hero, curated tools section, recent activity, experience highlights, update section, subscription section, support CTA, and promo area.
- Restyled the Tools, Updates, Requests, Settings, Search, Notifications, and modal sheets to match the new premium language.
- Added subtle reveal-on-scroll motion and a top scroll progress bar so scrolling feels more alive.
- Kept the existing ToolCart functionality and APIs while redesigning the front-end presentation.

## Files changed
- index.html
- styles.css
- app.js
- VERSION

## Notes
- No D1 migration required.
- Backend routes, auth flows, payments, and data models remain unchanged.
