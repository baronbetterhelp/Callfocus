# CallFocus V15.27 Visual Test — Unified Dark Theme

Built directly on **V15.26 Visual Test**. Stable V15.16 remains the approved stable base unless a visual-test branch is explicitly promoted.

## Changes

- Fixed the mobile dark-theme header so it no longer turns white.
- The dark header now uses a solid charcoal surface, while keeping the CallFocus logo, wordmark, tagline and menu control clearly visible.
- Reworked the **Less interface. More room for the conversation.** section from a green-heavy background into the same black/charcoal visual family used by the surrounding dark story cards.
- Retained restrained emerald and gold accents inside the dark theme without washing entire sections in green.
- Updated the conversation-stage borders, rings, tags, caller tiles and supporting text for consistent dark-theme contrast.
- Pearl/light-theme rules are untouched and remain light.

## Unchanged

Calls, credits, payments, referrals, authentication, saved information, Quick Start admin controls, voice notes, Recent Calls and backend behavior are unchanged.
