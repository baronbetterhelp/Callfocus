# ToolCart Product Manager Update

Built directly on the existing ToolCart V2.2 Product Marketplace Merge.

- Moves Products into the Admin Tools section.
- Adds an in-page Tools / Products switch.
- Adds a Tool / Product switch inside the Add modal.
- Removes the separate Products item from the Admin sidebar.
- Allows a product to contain any number of protected image/PDF files.
- Supports adding more product files later and removing files while editing.
- Purchased users can open every file included with the product.
- Existing single-file products are preserved by the migration.
- No unrelated customer-homepage or ToolCart design changes were made.
