# CallFocus V15.0 — Worldwide Location Search

- Replaced the fixed short city list with worldwide place autocomplete backed by a global geocoding search.
- Search results include city/place, state or first-level region when available, country, and the correct IANA time zone.
- Added all browser-supported IANA time zones to the manual time-zone selector as a fallback.
- Added small clear-location buttons to Caller A and Caller B location fields.
- New-call location fields now start empty and show example placeholders instead of pre-filling a real/account location.
- Repeat-call location editors also support worldwide search and clear buttons while preserving the saved last-used location until the user changes it.
- Both location and time zone are required before a new call can start.
