# CallFocus V11.24

Small Recent Calls navigation update built directly on V11.23.

## Added in V11.24

- Added a dedicated **Close conversation** button to an open Recent Calls thread.
- On mobile, closing a conversation returns the user to the Recent Calls conversation list/drawer.
- On larger screens, closing clears the active thread and leaves the saved conversation list visible for the next selection.
- The button is neutral and separate from the existing red Delete conversation control, so closing a chat never deletes it.
- Keeps the Pearl Aurora theme and all V11.22 Paystack reconciliation fixes unchanged.

## Important behavior

**Close** only exits the currently open conversation screen. It does not remove the caller, thread, call history, or any saved data.
