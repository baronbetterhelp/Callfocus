# CallFocus V15.10 — Compact Telegram Quick-Start Action

Built directly on V15.9.

## Change

The Telegram area inside the Home quick-start popup is now merged into one compact action card, matching the YouTube guide action above it.

The previous duplicated Telegram introduction row has been removed. The single Telegram action now shows:

- **Join the CallFocus Telegram channel**
- **Get updates, useful tools and CallFocus announcements**

The existing Telegram destination, 2-second quick-start appearance, 8-second auto-minimize behavior, floating alternating YouTube/Telegram button, unread badge, video guide, drag behavior, and Home-only visibility are preserved.

## Versioning

Customer/admin asset references and `/api/app-version` are updated to `15.10`. No account, payment, call, credit, saved information, admin, billing, or backend behavior was redesigned.
