# CallFocus V15.52 Visual Test — Editable Custom Voice Profiles

V15.52 is a targeted customer voice-profile update built directly on V15.51.

## What changed
- Every saved custom AI voice shown in New Call, Repeat Call, and Voice Notes now has a visible Edit control directly on the voice card.
- Tapping Edit opens the existing AI Voice Designer pre-filled with that voice profile.
- Customers can change the voice name, presentation, accent, age impression, warmth, energy, speaking speed, softness/assertiveness and optional description.
- Saving keeps the same voice-profile ID, so calls/threads already linked to that profile continue using the edited version instead of creating a duplicate.
- Updated voice profiles continue to save to the signed-in CallFocus account through the existing local + cloud synchronization flow.
- Existing Create voice and Delete controls remain available.
- No changes were made to calls, credits, billing, payments, referrals, admin email campaigns or live voice providers.

Build/app version: `15.52-test`.
