# CallFocus V13.0 — Avatar Conversation Setup

Built on V12.9.

## Changes
- Reorganized the three homepage quick tools into one compact, left-aligned three-card row beneath Start a new call.
- Reworded personal selfie avatar access as a professional Coming soon feature, with no customer-facing subscription/plan wording.
- Removed repetitive AI-generated badges, disclosure card and watermark from the Live Avatar page while retaining the clear Live AI Avatar feature title.
- Added Conversation setup / Call details before a live avatar session. Users can provide up to 4,000 characters of context, purpose, background, topics or desired outcome.
- The session brief is sent server-side into the Tavus conversation context so the avatar follows the requested scenario instead of responding generically.
- Session details are not saved to the CallFocus account; they are sent with the live session context and the field is locked while the session is active.
- Simplified customer-facing provider/setup copy so internal Tavus plan/API details are not exposed.

Manual payment fallback, Paystack recovery, admin controls, voice profiles and all previous functionality are preserved.
