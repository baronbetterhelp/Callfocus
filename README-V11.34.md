# CallFocus V11.34 — New-account Home landing

This build changes only the post-signup landing behavior.

## Fixed
- After a user creates and verifies a new CallFocus account, the site now navigates to `/` and lands at the very top of the main Home hero.
- The browser no longer preserves the signup-page scroll position and drops a new user directly onto the lower "Your workspace" section.
- Existing sign-in behavior is unchanged.
- Password-reset behavior is unchanged.
- Existing V11.33 payment-disable state and all previous Paystack, routing, Recent Calls, voice-note and conversation-dynamics features remain intact.
