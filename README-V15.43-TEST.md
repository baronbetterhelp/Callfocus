# CallFocus V15.43 Visual Test — Curved Live Continuity Core & Continuous Floating Ring Motion

Built directly on **V15.42 Visual Test**. Stable V15.16 remains the approved stable base unless a visual-test branch is explicitly promoted.

## What changed

- The **Live continuity** center core on the Home page now uses a more curved, dimensional green treatment so it matches the richer rounded look of the darker conversation-stage centerpiece instead of appearing flat.
- The caller core now has a stronger radial highlight, deeper inner shading, a subtle glass sheen and a softer depth ring for a more premium curved surface.
- The floating promo/help button’s outer circular motion has been rebuilt with smoother curved arc segments so the orbit looks more polished and rounded.
- The circling motion around the floating promo/help button now keeps moving continuously while the customer scrolls instead of pausing until scrolling stops.
- Reduced-motion behavior is preserved for accessibility.

## Unchanged

V15.42 mid-call continuation semantics, live-call redirect behavior, payments, referrals, admin tools, notifications, voice notes, Recent Calls, themes and unrelated call controls remain unchanged.
