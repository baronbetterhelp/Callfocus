# ToolCart V1.1 — Brand Standardization

## Changes

- Standardized the official product name to **ToolCart** across browser title, PWA manifest, Admin header, and transactional email footer.
- Removed **ToolCart Ecosystem** as a product-name label; “ecosystem” remains only as descriptive language where appropriate.
- Replaced the temporary purple app mark in visible site branding with the official ToolCart cart/share logo supplied by the owner.
- Regenerated the 192 px, 512 px, and Apple touch icons from the official logo.
- Bumped the service-worker cache so existing installations receive the new branding assets.
- Synced the Complete build with the current live non-secret D1 database ID and workers.dev APP_ORIGIN.

No database migration or account-data change is required for this release.
