# ToolCart V1.0 - Foundation Changes

V1.0 is the first ToolCart baseline, so every application file in this package is new.

## Foundation delivered

- Cloudflare Worker API and static routing
- D1 relational schema and migrations
- R2 media structure
- Resend verification/reset structure
- Paystack server-authoritative payment flow
- Customer authentication and persistent sessions
- Premium signed-out and signed-in mobile-first UI
- Dynamic app launcher, favorites, recent activity and search
- Updates, requests and notifications
- Profile, security, devices, subscriptions and payment history
- Separate `/admin` portal and admin authentication
- Admin dashboard, customer management, app management, plan management, payments, updates, requests, notifications, analytics, appearance, settings/promotions, audit log and diagnostics
- Midnight/Pearl themes
- PWA manifest, PNG/SVG icons and service worker
- Deployment documentation and production checklist
