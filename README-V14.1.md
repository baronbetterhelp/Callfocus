# CallFocus V14.1 — Manual Payment Approved Success Return

- After a manual bank-transfer payment is approved by the admin, the customer now sees a payment-confirmed success state inside the waiting modal.
- The waiting dots change to an animated green check, the copy confirms the added credits, and the modal shows a redirect message.
- The customer is then automatically returned to the Credits page instead of Home, with the refreshed balance visible there.
- The success state also includes a Return now button for immediate navigation.
- Manual payment request, receipt upload, approval, rejection, email approval links, and wallet crediting logic are otherwise unchanged.
