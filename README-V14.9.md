# CallFocus V14.9 — Human Voice Note Delivery

- Reworked voice-note reply drafting so generated messages sound like a real person recording a private phone voice note rather than an assistant or scripted response.
- Added dedicated voice-note rules adapted from the live-call behavior: natural familiarity, emotional matching, contractions, varied sentence length, fewer questions, no interview pattern, no unnecessary summaries, no invented personal facts, and no assistant-style openings.
- Live-call-only instructions are now explicitly adapted for one-way voice notes instead of being followed literally.
- Strengthened TTS delivery guidance for both Create voice note and Reply with voice note modes: relaxed pacing, breath-sized pauses, varied intonation, natural connected speech, understated emphasis, relationship-aware warmth, and no announcer/customer-service cadence.
- Script mode still preserves the user’s exact written words; only the vocal delivery is made more human.
- Reply mode still drafts the spoken words from the user’s intent, but now follows the new human conversational voice-note rules before audio generation.
- Existing voice selection, custom AI voice profiles, credits, wallet billing, history, and admin speech settings are unchanged.
