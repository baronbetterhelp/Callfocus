# CallFocus V13.1 — Compact Credits Screen

Built on V13.0.

Changes:
- Removed the New-user starter credit panel from the Credits page.
- Reduced the Available balance and Standard rate section into compact summary cards.
- Reorganized credit purchase presets into a compact three-option row on mobile.
- Tightened the custom-credit entry section and moved the primary payment action much higher on the screen.
- Reduced spacing and card height while preserving existing credit validation, manual bank-transfer, Paystack, receipt upload, approval, and wallet functionality.
- Simplified the public bank-transfer notice so internal Paystack activation status is not exposed.
