# CallFocus V15.11 — Telegram Quick-Start Icon Alignment

Built directly on **V15.10**.

## What changed

A small UI refinement was made in the Home quick-start popup:

- The trailing icon on the **Join the CallFocus Telegram channel** action now matches the **Watch how to use CallFocus** action.
- The previous Telegram trailing external-link style symbol was replaced with the same clean chevron style used on the YouTube action.

## What stayed the same

- The Home quick-start popup still appears after 2 seconds, auto-minimizes after 8 seconds, and can be manually minimized.
- The draggable floating help button, alternating YouTube/Telegram state, unread badge, animated ring, embedded video guide, and Telegram link behavior are unchanged.
- No payment, credit, call, authentication, saved-information, admin, billing, or backend logic was changed.

## Versioning

Customer/admin asset references and `/api/app-version` are updated to `15.11`.
