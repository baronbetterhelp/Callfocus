# CallFocus V15.1 — Telegram Channel Widget

Built on V15.0 Worldwide Location Search.

## Added
- Home-page-only Telegram promotion linked to https://t.me/callfocus
- Promo appears after 10 seconds on Home
- Promo automatically shrinks after 5 seconds into a floating Telegram button
- Floating button is draggable and can be moved around the viewport
- Tapping the floating button reopens the Telegram promotion
- Telegram UI hides immediately on all non-Home routes and returns safely when Home is opened again
- Existing CallFocus features, pricing, calls, voice notes, credits, payments, recent calls, authentication, admin behavior and responsive layout are preserved
