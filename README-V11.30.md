# CallFocus V11.30 — Uniform Recent Call Cards

This update is intentionally limited to the Recent Calls preview cards shown in the workspace.

## Changed
- every Recent Calls preview card now has the same fixed height
- the conversation detail preview is limited to one line with an ellipsis
- long call titles and caller/time text can no longer stretch a card
- the full conversation details remain available after opening the conversation
- spacing, avatar alignment and arrow alignment are kept consistent on mobile and desktop

## Preserved
- V11.29 compact call-history layout
- V11.28 routing/navigation work
- V11.22 Paystack reconciliation/payment fixes
- existing call, voice-note, account and admin functionality
