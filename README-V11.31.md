# CallFocus V11.31 — Remove Home Saved Callers Panel

Built directly from the V11.30 complete build.

## Change in V11.31
- Removed the entire **People / Saved callers** panel from the signed-in home page.
- The dedicated **My Callers** page remains available through normal navigation.
- Recent Calls cards, payment logic, routing, voice features, admin controls, and the Pearl Aurora styling are unchanged.

## Packaging
Two packages are provided for this release:
1. Changes Only — only the files changed in V11.31.
