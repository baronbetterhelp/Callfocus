# CallFocus V15.53 Visual Test — Auto-Fill Sheet Mobile Position

V15.53 is a targeted mobile layout refinement built directly on V15.52.

## Changed

- Moves the **Generate all caller information** first-call auto-fill sheet farther down on phone screens so the eyebrow, title, description and close button no longer sit too close to the iPhone status/browser area.
- Keeps the sheet bottom-anchored while reducing its maximum mobile height to preserve the new top breathing room.
- Uses a slightly smaller offset on unusually short mobile viewports so the form still has enough usable space.
- Resets the auto-fill sheet to the top every time it opens, preventing a previous internal scroll position from making the heading appear clipped.

## Unchanged

- Screenshot upload/generation behavior.
- First-call auto-fill limits and AI generation.
- Saved caller information.
- Custom voice editing from V15.52.
- Calls, credits, payments, referrals, promotional email studio and admin behavior.

Build/app version: `15.53-test`.
